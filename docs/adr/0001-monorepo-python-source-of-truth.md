# ADR 0001: One monorepo; Python is the source of truth

- Status: Accepted (2026-10-05)

## Context
The hackathon code implemented physics and ML features twice, in TypeScript and Python, held together by hand-written golden tests. The two copies drifted apart: for example, three SAA models and four copies of the action costs.

## Decision
- One repository holds `orbitlife` (Python, PyPI), `orbitlife-build` (private builders), `@orbitlife/core` (TypeScript, npm) and the web app.
- All physics and ML live in Python. TypeScript only interpolates grids that Python publishes, runs ONNX models that Python exports, and does light geometry.
- Golden fixtures generated by Python check that the TypeScript results match.

## Consequences
- A physics change is made once and cannot silently diverge.
- The browser can't compute anything Python hasn't published as a grid or model. That's an accepted limit.
- CI must run both toolchains.
