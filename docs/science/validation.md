# Validation status

Generated by hand at the Phase 1 exit (2026-10-06). From Phase 2 on, this page is regenerated from `just validate` output with residual plots.

## Phase 1: specification only
The suite holds **19 reference cases** across five modules: drag 2, forecast 4, orbit 4, radiation 7, SEL 2.

No physics code exists yet, so every case reports NOT_IMPLEMENTED and the strict run is red, as intended.

**16 cases are implementation checks**, which compare against the same models a reference code uses. **Only 3 compare against real measurements:**
- the Starlink Group 4-7 storm drag increase
- the two Shields-1 dosimeter readings

We **expect all three to fail** with empirical models. NRLMSIS-class density models under-predict storm drag, and the source's own AP8/AE8 model already sits 2.05× and 2.56× below the Shields-1 measurements. Two same-model cases reproduce that source model so the miss can be partly attributed (Phase 1 extension E2).

Some references need caveats:
- **Two SSO-inclination references** are our own evaluation of a published formula (UNVERIFIED).
- **One eclipse reference** corrects an arithmetic error in its source.

Several roadmap cases are still missing, each recorded in [`docs/open-issues.md`](../open-issues.md) with its reason:
- CREME96 per-bit SEE rates
- an SEL case with a published Weibull fit
- the beta angle
- ISS decay between reboosts
- on-orbit memory upset rates
